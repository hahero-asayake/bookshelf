# S6：ハヘロ向け実機確認手順（イシュー#513）

PC と iPad で、下の5つを確かめてください。スクショは `_trash/513-shots/`（自動撮影・機械実測用、参考）。

## 確認項目

1. **設定を開く→戻る**：サイドバーの「設定」を押してモーダルを開き、ブラウザの「戻る」を押す → ホームに戻る（アプリの外（タブが閉じる・真っ白になる等）には出ない）。
2. **公開の一覧→公開の設定→戻る2回**：「公開」を押して一覧を開き、公開の設定へ進み、「戻る」を2回押す → 1回目で一覧に戻り、2回目でホームに戻る（1段ずつ）。
3. **本の詳細→戻る**：本をクリックして詳細を開き、「戻る」を押す → 一覧（ホーム）に戻る。
4. **iPad横（1024px）で手動追加**：⌘K から「本を手動追加」→タイトルを入力した状態で「戻る」 → 「破棄しますか？」の確認が出る（これまでは確認なしで消えていました）。
5. **「←」は親へ行くだけ（戻るとは別）**：記事を編集中に左上の「←」（一覧へ戻る）を押す → 一覧に戻るが、ブラウザの「戻る」「進む」の段は消費しない（戻る/進むの動きとは別もの、という決まりのままです）。
6. **リロードしたときの動き**：通報の画面（記事フッタの「通報」リンクから開く画面）を開いたままページを再読込すると、画面が開き直ります。それ以外の画面（設定・公開・長文メモ等）を開いたまま再読込すると、段は畳まれて一覧やホームに戻ります（通報だけが特別で、他は今までと同じです）。

## フラグの切り替え方（元の動きに戻したい時）

設定 → 「このアプリについて」 → **「PC・タブレットでも戻るを1段ずつにする（新しい動き）」** のチェックを外す。
外すと、以前の動き（PCでは戻るでアプリの外に出る・1024幅の手動追加で確認が出ない）に戻ります。このチェックは既定でON（新しい動き）です。
このフラグは **2026-11-17** を目安に撤去予定です（②が別イシューで起票します）。
