    公開
    公開ページの作成・公開は、PC 画面左の「公開」ボタンから行います。ここではその公開の設定をします。 公開ページに「○○ の本棚」「© ○○」として表示されます。未入力ならアカウント名から仮の名前を使います。

    公開ページ（HTML）の書き出し先です。中身は誰でも見られるので、公開専用の空 public リポジトリを選んでください。
    リポジトリの作り方と公開URL
    空の public リポジトリ（例 bookshelf-public）を作り、bookshelf-sync アプリのアクセス対象に追加すると、ここで選べるようになります。GitHub Pages（Settings → Pages → Source = main）を有効にすると https://<owner>.github.io/<repo>/ で見られます。
    Asayake ハブ（hahero 運営）へ直接公開します。GitHub は不要で、Google ログインだけで公開 URL が手に入ります（中身は誰でも読めます）。
    Amazon アソシエイトに参加している方向けの設定です。
    蔵書

    Amazon の蔵書一覧から、持っている本をまとめて登録します。

    Kindle 以外の本や紙の本を、1 冊ずつ入力して追加します。

    本棚に置かないことにした本の確認と、元に戻す操作ができます。

    プラグインは開発者向けの機能です。通常の利用に設定は不要です。

    新しいプラグインを追加上級者向け

    リポジトリURLからインストール

    プラグインのファイル（manifest.json と index.js）が置かれた GitHub の場所を貼り付けます。例: https://github.com/owner/repo/tree/main/plugins/foo
    プラグインは外部のコードとして実行されます。信頼できる配布元のものだけを導入してください。

    手動でインストール

    同期フォルダの plugins/<プラグインid>/ に manifest.json と index.js を置くと、次回読み込み時に自動で認識されます。

    プラグインを自作したい方へ: プラグイン開発ガイド（最小構成・API・イベント・配布方法）

        取込は PC 専用です。PC のブラウザでこのアプリを開いて取り込んでください。取り込んだ本はこのスマホでも見られます。

        1. 1「Kindle取込」ボタンをブックマークバーに登録する最初の1回だけ

          下の点線のボタンを、ブラウザ上部のブックマークバーへそのままドラッグします。

          Kindle取込←これをドラッグ
          ドラッグできない・ブックマークバーが見えないとき

          ブックマークバーは Ctrl+Shift+B で表示できます。ドラッグできないときは下のボタンでコードをコピーし、ブックマークを新規作成して URL 欄に貼り付けてください（名前は「Kindle取込」がおすすめ）。

        2. 2Amazon の蔵書一覧を開く
        3. 3開いた Amazon のページで、登録した「Kindle取込」を押す

          本の一覧が自動でこの画面に届き、取り込む本を選べます。
